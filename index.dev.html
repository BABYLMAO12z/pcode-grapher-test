⚡ PCODE Grapher — chưa chạy được từ đây

File index.html này là bản dev (cần Vite). Chọn một cách chạy:

  • Chạy ngay không cần npm: phục vụ thư mục gốc qua HTTP (app đã build sẵn trong assets/) — ví dụ đặt Tool Dir của bridge Ghidra trỏ vào thư mục này rồi mở URL bridge in ra.
  • Dev (live-reload): npm install rồi npm run dev (tự mở /index.dev.html).
  • Build lại bản tĩnh: npm run build — script tự cập nhật index.html + assets/ ở gốc.
